All endpoints require auth via session cookie or a Bearer token from /api/token.

Authentication
POST/api/token
Body: {"username":"...","password":"..."} → bearer token.
Runs
POST/api/runs
Create a run. Returns run_id.
{"name":"cifar100-exp-01","dataset":"cifar100","methods":["DLG","iDLG"], "num_dummy":1,"iterations":300,"lr":1.0,"num_classes":100}
GET/api/runs
List all runs.
GET/api/runs/:run_id
Get metadata for a single run.
Upload
POST/api/runs/:run_id/metrics
Upload loss/MSE arrays or stream per-iteration values.
# Full arrays at end of run {"method":"iDLG","loss":[0.5,0.3,...],"mse":[0.2,0.1,...], "final_loss_iDLG":0.000042,"final_mse_iDLG":0.00012,"label_iDLG":7,"gt_label":7} # Stream per iteration {"method":"DLG","append_loss":0.3421,"append_mse":0.1204}
POST/api/runs/:run_id/images
Multipart upload (field: file) or base64 JSON. Accepts .png .jpg .gif .webp
POST/api/runs/:run_id/data
Multipart file upload. Accepts .pkl .npy .npz .json .csv .txt
POST/api/runs/:run_id/logs
Append to log. Set "append":false to overwrite.
{"filename":"run.log","content":"iter 50 loss=0.34","append":true}
Python Client
